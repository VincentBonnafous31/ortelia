# Tâches : etat-de-session

Toutes les commandes `cargo` se lancent dans WSL2, avec `CARGO_TARGET_DIR=~/target/ortelia` (voir `CLAUDE.md`). Chaque tâche laisse le workspace compilable, Clippy sans avertissement et les tests au vert. « Un test par scénario » renvoie aux scénarios des spécifications du changement. Consulter Context7, ou les sources des crates dans `~/.cargo/registry/src/`, avant d'écrire du code qui utilise eframe, egui, egui_kittest, serde ou serde_json. Les tests qui écrivent un fichier d'état travaillent sur une copie de `examples/annuaire` dans un dossier temporaire, jamais dans `examples/`.
